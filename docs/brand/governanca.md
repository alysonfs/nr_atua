# Governanca de marca do ATUA

## Fonte de verdade

O manifesto estabelece os fundamentos. Estrategia, identidade e voz registradas
nesta pasta orientam os entregaveis de marca do ATUA.

## Acionamento

O `orchestrator` aciona os agentes de marca sob demanda para tarefas que
requeiram posicionamento, identidade externa, texto, conteudo ou revisao.

## Responsabilidades

- `brand-strategist`: decide estrategia, posicionamento e mensagens.
- `brand-identity`: define a expressao visual externa.
- `brand-copywriter`: redige conforme a voz aprovada.
- `brand-content`: planeja conteudos no escopo delegado.
- `brand-guardian`: revisa consistencia quando solicitado.

## Revisao

O guardian pode bloquear apenas o entregavel de marca que revisa. A aprovacao de
software continua com QA, e a preparacao de release continua com
release-versioning.
